# Project Repository

This repository contains the GroceryGo Android app under grocery_ordering_app_frontend.

Build tips:
- From repo root: ./gradlew :grocery_ordering_app_frontend:app:assembleDebug
- If your environment resets executable bits, call: bash gradlew
- Or change directory and run: cd grocery_ordering_app_frontend && ./gradlew :app:assembleDebug
- You can also use: make build
